# BuildTrack Material Manager

BuildTrack Material Manager is a simple CRUD-based web application developed using React and Vite.  
The application helps manage construction materials by allowing users to add, view, update, and delete materials.

---

## Features

- View all materials
- Add new materials
- Edit existing materials
- Delete materials
- Premium responsive UI design
- Connected to MockAPI backend

---

## Tech Stack

- React + Vite
- JavaScript
- Axios
- MockAPI

---

## Mock API Solution Used

This project uses MockAPI for backend simulation.
